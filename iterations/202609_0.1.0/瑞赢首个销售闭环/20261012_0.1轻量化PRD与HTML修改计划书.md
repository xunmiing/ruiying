# 瑞赢 0.1 轻量化 PRD 与 HTML 修改计划书

> 日期：2026-10-12  
> 计划依据：[0.1 轻量化与 H5／PC 结构调整说明](20261012_0.1轻量化与H5-PC结构调整说明.md)  
> 计划状态：已执行。本文件记录改动、顺序和验收；正式业务口径以 PRD 为准。2026-10-12 已按任务默认“全部”和 H5 单一团队入口完成回写；历史页面归档及浏览器回归见本期更新记录。

## 1. 交付目标

将已确认的轻量化决定同步到 0.1 正式 PRD、PC 与 H5 HTML 原型，并清理已退出功能的入口、页面说明和验收引用。完成后应满足：

1. H5 方便销售个人执行，主管／经理使用同一个 H5 处理少量团队业务；PC 方便主管管理团队并继续开展个人销售。
2. PC 客户、线索、商机、任务、日报从菜单进入时，数据范围统一为“全部可见范围”；状态、时间独立设置。
3. 客户列表为“全部｜团队｜我负责的｜我协作的”；任务列表默认全部可见正式任务，状态和时间不限制；日报状态不限制、时间默认当天；客户、线索、商机状态和时间不预选。
4. 从详情返回原列表时恢复 Tab、筛选、排序、页码。
5. PC 管理分析、指标配置，以及数据质量、集成、消息投递、系统审计的独立管理查询页面退出 0.1；基础业务功能及必要后台记录继续存在。
6. 系统管理呈现“人员组织与权限、业务配置、异常事项、知识管理、AI 运行记录与失败处理”；业务配置具有明确子菜单。

### 2.3 本轮不擅自决定的事项

- 任务列表默认全部可见正式任务，状态和时间不限制；“今日／本周／逾期／待处理”等仅在用户选择后生效。
- 除客户外，各列表 Tab 的最终文案和完整集合应依据正式对象关系核对；已确定“全部默认、团队优先、个人范围可切换”。
- H5 不照搬 PC 的“全部默认”列表规则；H5 工作台的团队快捷入口合并为一个“团队处理”入口。
- 技术日志字段、保存期限、查询工具及告警实现由技术确定；产品只固定需要记录的事件范围与责任边界。

## 3. 执行顺序与每阶段产物

依次完成 PRD 定义、公共原型结构、PC 列表、PC 系统管理、H5 校对、验收与全局核对。每阶段应有可单独检查的结果，避免 PRD 与页面长期指向不同范围。

| 阶段 | 目的 | 主要产物 | 完成判断 |
|---|---|---|---|
| A. 基线与引用盘点 | 找全实际入口和现存冲突 | 页面／脚本／PRD／AC 影响表 | 被移出页面的菜单、深链、清单和验收引用已登记 |
| B. PRD 回写 | 先形成统一正式口径 | 总 PRD、00～08 相关章节 | 范围、状态、权限、日志和页面边界无互相矛盾表述 |
| C. PC 公共结构 | 先改共用导航和清单 | 导航、权限映射、页面清单、页面说明 | 系统管理和业务配置入口与 PRD 一致，退出页面不在本期导航 |
| D. PC 业务列表 | 改默认值及返回行为 | 五类列表和关联详情 | 菜单进入、详情返回、范围及独立筛选均符合规则 |
| E. PC 管理页面精简 | 收敛人员入口与技术页面 | 人员管理入口、业务配置子菜单、异常／知识／AI 入口 | 业务操作可达；技术查询页不作为 0.1 菜单或交付页面 |
| F. H5 校对 | 保持个人执行重点 | 工作台和轻量团队入口、页面说明 | 主管源业务动作可达，未增加完整管理端 |
| G. 验收与收尾 | 保证交付清单可执行 | 用例、变更记录、范围摘要 | 页面、PRD、AC、用例及演示路径一致 |

1. 核对总 PRD、00～08、页面清单、权限项及 `testcase.md`：没有把管理分析、指标配置或已退出技术查询页列为 0.1 交付。
2. 对任务验收／退回、日报退回重提、旧角色 R4／R5、旧消息个人偏好等历史正文进行定向扫描；保留版本历史，但当前有效规则不得冲突。
3. 核对客户关系网、经营关系、普通导出、日志记录和正式鉴权规则没有因删减页面而丢失。
4. 对照 `PROJECT.md`、`CURRENT.md`、相关长期资产及变更记录，将明确写作“本期范围”的旧摘要同步更新；保留历史决策原文。

### 7.2 HTML 行为检查

| 场景 | 预期 |
|---|---|
| 销售、主管分别从 PC 菜单打开五类列表 | 均从“全部可见范围”进入；角色只影响实际可见记录 |
| 客户四个范围切换 | 顺序正确，按有效经营关系判断，单范围内客户 ID 去重 |
| 三类列表无默认状态／时间 | 客户、线索、商机进入时不预选状态与日期 |
| 任务、日报默认 | 任务全部可见且状态／时间不限；日报当天且状态不限 |
| 列表 → 详情 → 返回 | Tab、筛选、排序、页码恢复；从菜单再次进入采用默认值 |
| PC 系统管理 | 一个“人员组织与权限”入口，业务配置八个子菜单，异常／知识／AI 记录可达 |

HTML 检查需要在浏览器中完成实际点击及返回。静态搜索只能证明文字和引用发生变化，不能证明交互可用。

### 7.3 交付记录

完成后列出实际修改文件、删除或归档的原型页面、关键交互验证结果，以及 PRD 与原型仍有差异的事项。更新迭代与原型变更记录，避免只修改页面而遗漏正式范围。
