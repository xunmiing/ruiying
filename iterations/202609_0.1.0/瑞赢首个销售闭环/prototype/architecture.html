两端定位

H5 优先方便销售个人执行，主管／经理共用同一个 H5，工作台仅有一个“团队处理”入口，可进入团队线索、任务、日报和拜访。

PC 优先方便主管／经理管理团队，也支持其个人销售及销售人员使用。首页是轻量入口页，业务导航为客户管理、销售管理、工作管理、系统管理。

任务与候选

正式任务只有待处理、已完成、已取消三个主状态。逾期是时间标记；待确认只属于 AI 候选任务。正式任务无接收、拒绝、验收或退回流程。一个任务 ID 只有一个负责人，可有多个参与人。

系统管理

前台保留人员组织与权限、业务配置、异常事项、知识管理、AI 运行记录与失败处理。业务配置有字典、商机流程模板、线索池、全国公海、区域与业务线、任务规则、拜访规则、Agent 配置八个子菜单。

本期边界 管理分析、指标配置及独立数据质量、集成同步、消息投递与审计查询页面退出 0.1。权限校验、同步重试、消息投递日志和审计记录仍由后台实现；相关审计记录由技术人员查看分析并处理，具体规则由技术定义。

上次提交后的增量（2026-10-15）

  • 会议任务：PC 与 H5 新建会议任务填写开始、结束时间和会议方式，并按线上／线下填写会议链接或地点；结束时间同时作为任务截止及到期计算依据，参与人从公司人员中查询多选，会议任务一期不发送企微邀请。
  • 任务与日历：任务时间列展示开始时间至截止时间；会议任务在统一日历按会议时段投影，不另生成重复的截止时间投影。
  • 个人速记（H5）：全局入口进入个人速记，支持语音或文本录入及本人历史；语音转写为原型模拟，正式转写和服务端保存仍待研发接入。速记仅本人可见，不自动写入任务、活动或日报。
  • 宽屏评审布局：桌面宽度下 H5 画布居中，悬浮入口留在画布内，PC 原型跳转显示在画布外侧；窄屏不显示该评审跳转。

范围以本轮 PRD 与原型改动记录为准；速记真实语音服务尚未验收。

本次新增（36df055 提交后）

  • 任务候选处理：“待确认”分为“当前待确认”和“写入失败”。未补齐必填信息的候选留在当前待确认；已确认但未写入正式任务的候选保留最终确认值、确认时间和失败原因，并单独显示。
  • 失败恢复：业务字段问题由原确认人补齐后手动重试，技术性失败可按原参数重试；每次重试重新校验权限、来源和对象状态，并核查原候选的幂等结果，避免重复创建任务。写入失败仍是候选处理状态，不是正式任务状态。

当前原型用于展示候选失败处理流程；服务端幂等、并发控制和权限校验仍需研发实现并联调验证。

销售业务主流程

按业务对象的典型推进关系展示；各环节也可从对应页面独立发起，不要求每条记录都依次经过所有环节。

1 线索录入、认领、分配与跟进；池内线索按规则流转。
2 转换从单条线索详情发起，创建或关联客户、联系人，并至少创建一条商机。
3 商机按流程模板推进阶段，记录阶段任务与协作。
4 执行记录普通销售活动或正式拜访；任务与日程承接下一步工作。
5 日报与回看汇总当日正式事实，销售补充后提交；主管在源业务页面查看与处理。

线索转换后保留源线索与追溯关系；客户、联系人、活动、任务和日程可以按各自规则独立创建。

Agent 辅助流程

来源与提炼从有权业务对象或沟通材料获取来源。
生成候选展示目标对象、拟写内容与来源证据。
人工处理发起人修改、确认或忽略；确认前不形成正式事实。
正式写入重新鉴权并逐条校验，返回正式对象 ID 或失败原因。
回到源业务成功项进入正式列表；失败项保留确认内容供处理。

Agent 辅助不替代手工业务入口，也不直接改变既有商机阶段或正式任务状态。

0.1 业务对象清单

按评审所需的主要业务对象与关联实体归组；同组名称不表示一张数据库表。字段、状态和操作规则以各模块 PRD 为准。

领域对象或关联实体保存的核心事实与边界
客户与关系客户主档唯一客户主体与身份；主档不保存销售负责人。
客户价值档案客户的公司级价值分级，与商机阶段分开。
经营关系客户 × 区域 × 业务线的负责人、协作人与经营状态。
全国公海记录零条有效经营关系客户的待分配占用；与线索池分开。
客户关系网客户与客户的关联关系；不在主档设置通用父客户。
联系人及联系人关系自然人基础资料，与一个或多个客户的任职／角色关系分开。
客户地址客户下的地址记录；拜访可引用地址快照。
销售推进线索待验证机会及跟进；单条转换可创建或关联客户、联系人与商机。
商机正式销售机会、主客户、负责人、阶段与结果。
商机业务线明细一条商机涉及的主／协同业务线，不另建商机。
商机流程模板版本化阶段、门槛与阶段任务配置，不替代商机实例。
执行与复盘普通销售活动已发生的沟通与纪要。
正式拜访独立拜访对象，保存计划、执行、证据与异常；与普通活动分开。
正式任务唯一负责人、协作人、截止与成果；拜访计划和阶段任务复用同一任务对象。
独立日程真实日程记录；任务、拜访及线索／商机关键时间在日历中作投影。
日报当日正式事实、销售补充和提交快照；提交后冻结。
AI 辅助Agent 候选与写入执行待确认内容与正式写入结果分开；确认前不形成正式业务事实。
