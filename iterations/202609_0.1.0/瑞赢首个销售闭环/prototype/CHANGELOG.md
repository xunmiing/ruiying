## 2026-09-23 · 商机详情两个 P0 修复（H5 阶段推进不可用、已关闭商机动作未禁用）

**依据**：批注层登记的待修项（2026-09-22 实测）；规则依据 prd/03 §7.2（顺序推进）、§12（休眠必填原因与复查日期）、§13（已关闭商机需先重开）。

### 一、P0-A：H5 商机详情阶段推进不可用

- **现象**：点「推进到下一阶段」抛 `ReferenceError: stageIndex is not defined`，阶段停在原阶段。
- **根因**：`h5/opportunity/detail.html` 的 `doAdvance()` 裸调用了未定义的全局 `stageIndex()`（共享层函数应写作 `S.stageIndex(o)`）；同文件已有包装 `idx()`。
- **改动**：改用上一行已计算的 `i = idx()` 判定（`if (!t || i < 0)`）。原先写在后面的休眠／关闭态守卫因此得以真正执行。
- **附带**：H5 推进／回退／休眠／恢复按钮的可用性补上状态判定（`!isClosed() && !isDormant()` 等），关闭或休眠的商机不再显示为可点；H5 休眠调用补 `sleepOpp` 返回值判断并提示原因。

### 二、P0-B：PC 商机详情已关闭商机的动作未真正禁用

### 业务口径（按 PRD 落实）

- **转派不经全国公海**：不产生公海记录、不改变客户与区域业务线归属、不新建经营单元；审计保留原主负责人与原因。
- **转派默认保留协作人**，也可同次调整；新主负责人不会同时成为自己的协作人。
- **指派与转派都不产生保护期**。原型对既有保护期的处理是**既不延长也不清除**——PRD 只确认「不产生」，未规定既有保护期的去留，原型不擅自决定，抽屉内已明确说明。

- 「无权限」表达：R1 已不再拥有 `relation.assign`／`relation.transfer`，入口保留并标注「无权限」。

### 本次修复（V0.15.1 引入的检查发现的新缺陷）

- **无权限入口点击会叠加两层提示**：`pc/customer/detail.html` 的按钮监听先按 `can()` 弹出「该动作当前不可执行」，随后 `navigation.js` 绑定在 `document.body` 上的 `bindDenied` 对同一 `[data-denied]` 按钮再弹一层，用户看到两个叠起来的弹窗。已在经营关系区的按钮监听中跳过 `data-denied` 入口，统一交给 `bindDenied` 表达拒绝（含权限公式说明）。**已用反向验证确认缺陷真实存在**：临时移除该守卫后，断言准确报出「层级数 2」；恢复后回到 1 层并全绿。

## V0.12.1 — 2026-09-15 · §6.25 深链参数与来源回跳

**依据**：`prd.md` §6.25（视图深链、统一参数、实现注意 1～4）与"必须实现的跳转路径（P0）"17 条。

### 1. 修复：带参数的深链此前全部落到 fallback

三份原型的路由分发都是 `let path=()=>location.hash.slice(1)||默认路由`，把 `?id=…&from=…` 连同路由一起拿去查 `R[q]`，因此**任何带参数的深链都命中不到路由**，直接落到兜底分支。这正是 §6.25"任一已登记路由可直接打开并落到对应视图"当时不成立的原因，也是本次 17 条 P0 路径全部不可用的根因。

修复：`path=()=>DL.hp().r||默认路由`，查询串交由 `DL.q()/DL.has()` 读取。

> 实现注意：`||默认路由` 不能省（index→`/entry`、manager→`/dashboard/team`、admin→`/template`）。§6.25 实现注意 3 要求无参数直接打开静态原型时落到该端首页；漏掉默认值时 `path()` 返回空串，菜单高亮与按 `path()` 查表的参数注入会一起失效。

### 2. 新增：`DL` 命名空间（三份文件同名同实现）

| 能力 | 说明 |
|---|---|
| `DL.hp/q/has` | 路由与查询分离（查询在 `#` 之后） |
| `DL.self/token` | 当前文件名 → `from` 令牌（`index` / `manager` / `admin`） |
| `DL.url(href,params)` | 给深链补参数，**已存在的键不覆盖** |
| `DL.tagLinks()` | 扫 `a[href]` / `[data-role-url]` / `[data-end]`，跨文件链接自动补 `from=<当前端>`（实现注意 1：跳转必须携带 `from`） |
| `DL.FROM/backLink()` | `from` 令牌 → 「← 返回来源视图」入口，**且回跳目标也带上当前端令牌**，来源链往返不断 |
| `DL.bar()` | 深链参数横幅（9 个统一参数全部透出）+「清除参数」 |
| `DL.GO` + `DL.post()` | 按当前路由给页内既有 `data-go` 按钮注入参数；只在点击时读取，不重新绑定 |

**为什么不改既有标记**：`from=` 全部在运行时补齐，三份文件的原始链接/按钮标记一个字未动，与 V0.12.0 的追加式改动保持一致。
